# Grid View（纯课表视图）—— Web 实现规格

> 目的：给 Web / Flutter 两个客户端统一“课表（Grid）视图”的交互与视觉基线。
> Web 已按本文实现并运行于 `/table`（导航名“课表”）。
> 数据契约以 `docs/openapi.yaml` 为唯一来源，结构化字段的线格式细节见
> `web-docs/api-wire-reference.md`；时间语义见 `docs/datetime.md`。

## 0. 一句话

把“时间轴周视图”换成**横=星期、竖=第几节**的纯课表：
没有时间轴、没有凌晨/午休/夜间行；事件按“落在哪些节次行”裁剪展示；
保留现在线、截止线、拖拽/缩放，并做 上午/下午 强分界。

## 1. 布局

- 7 列：周一…周日（ISO，周一=1）。
- 行 = 学期节次模板（`GET /calendars/{id}/periods`），按 **开始时刻升序**、同一开始时刻去重；行高建议 54px，左侧编号列宽 64px。
- 每行左侧：**大号节次编号**（1、2、3…，取模板 `periodNo`）+ 小字开始时刻（如 08:00）。
- **上午/下午分界**：以“第一行开始时刻 ≥ 12:00”的行作为下午起点；
  - 上午：淡蓝底 + 行号蓝色；下午：淡橙底 + 行号橙；
  - 两组之间画 2px 实线 + 居中胶囊“上午 AM · 下午 PM”。
- 周末列淡色底。顶部为固定星期表头（含日期、今天高亮圆点）。

## 2. 事件投影（行映射）

输入：整周范围的 `GET /calendar/events`（start=周一 00:00 用户时区，end=下周一 00:00），所有时间先归一化到用户不可变时区的“当天分钟”。

- **课程 / recurring_schedule**：占用其分钟区间命中的各行并合并为跨行色块；
- **Todo 时间块**：同样投影；两端只落一行时按真实分钟算行内局部高度；
- **裁剪规则**：
  - 完全落在无行时段（凌晨/午休/夜间等）→ **不显示**；
  - 部分跨无行时段 → 只画节次内的部分（午休段被裁掉）；
  - 事件连续跨过的“课间”空档（相邻行之间）因行相邻而自然合并，无需断开；
  - 命中不相邻的两组行（行间空档 ≥ 45min，如跨午休）→ 拆成多个独立色块。
- 多事件同一时间段重叠 → 用 lane 并排（与周视图同款区间着色算法）。

## 3. 现在线 & Deadline 线（点标记）

- **当前时间橙线**：横贯 7 列整行，按“当前分钟 → 行内位置”精确定位；左端橙胶囊「现在 HH:MM」。仅在“今天属于当前显示周”时显示。
- **Deadline 红标**：每日截止 = 红色胶囊（标题 + `MM-DD HH:MM`），定位到其分钟所在行；**悬停 tooltip 显示完整具体时间**（`任务名 · 截止 YYYY-MM-DD HH:MM`，用户时区）。
- **钉线规则（折叠时段内）**：当“现在/截止”分钟不在任何节次行内（即处于凌晨、课间空档、午休、夜间等被折叠/省略时段）时：
  - 凌晨（首节开始前）→ 钉在首节顶边；
  - 课间/午休（两行之间）→ 钉在相邻两行的分界线上；
  - 夜间（末节结束后）→ 钉在末节底边。

## 4. 交互

- 工具栏开关「课程可拖动/缩放」，**默认关闭**：
  - 关 → 仅 **Todo 时间块**可拖动/缩放；
  - 开 → 课程与周期安排也可拖动/缩放（均按单次 occurrence，见下）。
- **拖动（可跨天）**：
  - 按住色块移动；实时在指针所在星期列画**虚线幽灵预览**；松手提交。
  - Todo 时间块 → 直接 `PATCH /todo-blocks/{blockId}`（startAt/endAt，可跨天）。
  - 课程/周期 → `POST /series/{type}/{id}/apply`，`scope: THIS`、`occurrenceDateLocal=目标日期`；
    **服务端限制**：目标日期必须存在该系列上课日，否则 422，前端仅提示不产生脏数据。
  - 实现注意：拖动期间源块**只做透明隐藏、不得从 DOM 卸载**——卸载会释放 pointer capture，导致 pointerup 丢失、点击即消失（Web 端已踩过此坑）。
- **缩放**：
  - 上缘手柄 → 开始时间吸附到**上课时间**（节次开始时刻集合）；
  - 下缘手柄 → 结束时间吸附到**下课时间**（节次结束时刻集合）；
  - 最短时长 15 分钟；同 TODO 语义，缩放不跨午夜/不超过当日。

## 5. 数据与时间约定

- 只用 `GET /calendar/events`（含 include* 全开），本视图不做本地周期展开；
- “第几节”语义优先使用事件投影的 `metadata.periodStart / periodEnd`；
  分钟→行映射用于兼容被 move-override 后实际时间偏离模板的情况；
- 一律用户固定时区；不用设备时区；
- 文案统一中文（导航、按钮、吸附/折叠提示、图例、tooltip）。
